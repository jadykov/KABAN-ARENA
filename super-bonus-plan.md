## Уточнённая схема урона

При принятом сервером отпускании сохранить B: **12,5 HP при power < 0,8 и 25 HP при power ≥ 0,8**. **Прямое попадание = B + непосредственный E; дальнейший эффект = только его собственный E.** B наносится максимум один раз по цели и только летящим предметом. Если прямого попадания не было, последующий взрыв или облако не получает B. E сохраняет исходные бюджеты карточек; нынешний ×2 не добавляется.

| Предметы | Предлагаемый результат по одной цели |
| --- | --- |
| 02, 05, 14 | Прямое попадание 37,5/25 HP сильным/слабым броском; E = 12,5 HP. |
| 08 | 50/25 HP; E = 25/12,5 HP, один успешный удар за полёт, стена завершает его. |
| 01, 23 | Прямой удар: B. Взрыв всегда только E = 25 HP вблизи, 12,5 HP у края при любом заряде. Суммы 50/37,5 HP сильным и 37,5/25 HP слабым возможны лишь при прямом попадании и последующем взрыве по той же цели. |
| 16 | Прямой удар: B. Облако только E = 12,5 HP/с, максимум 25 HP за банку с повторными входами. Максимумы 50 HP сильным и 37,5 HP слабым требуют прямого попадания и полного урона облака по той же цели; только облако — максимум 25 HP. |
| 17, 18, 26 | Прямой удар летящим предметом даёт только B = 25/12,5 HP; последующее замедление, скольжение или притяжение наносит 0 HP. |

Для 01/16/23 B наносится только прямым попаданием, затем объект устанавливается на ближайший допустимый пол или крышу у места столкновения. Взрывы и облака по всем целям всегда наносят только E. Промах не переносит B на первое повреждение эффектом. Для 17/18/26 площадного B нет; установка тоже требует настоящей опоры. Подбор и земля сами по себе не наносят повреждения.

Щит поглощает добавленный B по общим правилам и расходует его однократный допуск даже при полном поглощении. Неуязвимый контакт не наносит урон/контроль и не даёт очков. Учёт по ID цели переживает её возрождение, имеет конечный срок и удаляется с последним эффектом броска. Лимит нескольких облаков 12,5 HP/с относится к E. Риск для автора сохраняется: возвращённый бумеранг, овца, взрывы и облако опасны и ему.
